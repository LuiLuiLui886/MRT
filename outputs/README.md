# MRT Link — Paket Awal

## Isi paket

- `mrt-link-prototype.html` — prototype mobile interaktif sekaligus wireframe.
- `mrt-link-proposal-pack.md` — positioning, evidence, KPI, pilot plan, risiko, struktur pitch, dan script demo.
- `screens/` — lima visual 1440×1000 yang siap dimasukkan ke proposal atau presentasi.

## Cara menjalankan prototype

1. Buka `mrt-link-prototype.html` di Chrome atau Edge.
2. Klik **Bandingkan perjalanan** untuk mengikuti alur utama.
3. Pada Detail Perjalanan, klik **Book Journey**, kemudian **Lihat demo perjalanan aktif**.
4. Pada layar Connection Assist, klik **Gunakan rencana baru**.
5. Gunakan tombol **Prototype/Wireframe** untuk mengganti tingkat fidelitas.
6. Saat presentasi di laptop, gunakan tombol panah kiri/kanan untuk berpindah antarbagian.

## Skenario prototype

Prototype menceritakan perjalanan ilustratif Cinere → Lebak Bulus → Dukuh Atas. Seluruh waktu, biaya, kendaraan, dan emisi di dalam prototype adalah data simulasi untuk menguji pengalaman pengguna, bukan klaim operasional.

## Rekomendasi positioning

MRT Link paling kuat bila diajukan sebagai **modul atau orchestration layer di dalam ekosistem MyMRTJ**, bukan sebagai aplikasi baru yang bersaing dengan MyMRTJ. Identitas terpisah pada prototype dipakai agar konsep mudah dipahami dan didemonstrasikan.
